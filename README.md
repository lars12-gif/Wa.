# 🌋 VOLCANO v2 — Fast Group Protection

نسخة حماية حديثة لـ WhatsApp باستخدام JavaScript + Baileys.

## الحماية الأساسية
- مسار الاستجابة المطلوب: **الطرد → الحذف → قفل المجموعة**.
- Contact Guard لرسائل `contactMessage` و `contactsArrayMessage`.
- Deduplication لمنع تكرار معالجة نفس الرسالة.
- Emergency Lock مؤقت أثناء الهجوم.
- معالجة متتابعة للهجمات المتتالية.
- رسالة دفاع تلقائية مع صورة Volcano.
- لا يعمل Security Engine إلا في المجموعات التي تم تنصيبها.

## Pairing Code
- لا يوجد QR.
- جلسة الربط الأولية مدتها **180 ثانية (3 دقائق)**.
- إذا لم يحدث الربط، تُغلق الجلسة وتُنظف بيانات المصادقة المؤقتة.
- بعد نجاح الربط، لا يوجد مؤقت 3 دقائق على الجلسة الدائمة.

## الأوامر
`.تنصيب` — تفعيل الحماية للمجموعة الحالية.
`.إلغاء` أو `.الغاء` — إيقاف الحماية.
`.حالة` — عرض الحالة.
`.مساعدة` — عرض الأوامر.

## التشغيل
```bash
npm install
cp .env.example .env
npm start
```
ضع `PHONE_NUMBER` بدون + أو مسافات، مع رمز الدولة.

## الاستضافة
ارفع المشروع إلى GitHub، ثم شغّل Node.js 20+.
يجب توفير Persistent Storage لمجلد `auth/` حتى لا تضيع جلسة WhatsApp بعد إعادة تشغيل الخدمة.

## الصلاحيات
يجب أن يكون حساب Volcano مشرفاً حتى يستطيع الطرد والحذف والقفل. إذا كان المرسل مشرفاً فلن يحاول البوت طرده.

## ملاحظة تقنية
Baileys 7.0.0-rc14 هو الإصدار الحالي المنشور على npm وقت إعداد المشروع. Baileys يوصي بتخزين auth بشكل إنتاجي في قاعدة بيانات/مخزن مخصص بدلاً من `useMultiFileAuthState`؛ هذه النسخة تستخدمه كبداية بسيطة متوافقة مع استضافات GitHub/Node.
